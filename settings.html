Template workbench

Four independent templates, each stored in Cloud Firestore with its own version history. Uploading or editing never overwrites anything until you press Save.

Before you save

  • Template code is trusted content. In previews and PDFs, scripts are not executed, and external images, fonts or stylesheets may behave differently than in a normal browser tab.
  • Design inside one fixed-size root (default 640 × 960 px). To use another size add <meta name="card-size" content="WIDTHxHEIGHT">.
  • The PDF renderer ignores clip-path, filters and blend modes. Prefer inline SVG for angled shapes.
  • The password gate only hides this screen. It does not secure Firestore. See the README.
